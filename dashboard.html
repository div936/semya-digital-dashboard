        Inventory Settings
      

      
    


    
    
Set Stock Quantity — One SKU at a Time

    
Warehouses need to exist first — set those up on the UTM Analytics tab. Changing the quantity here is logged as a manual adjustment; automatic deductions from sales happen on their own as files are uploaded, no need to re-enter anything for those.

    

      

        
        
      

      

        
        
      

      

        
        
      

      

        
        
      

      
    

    


    
Or Upload Stock Counts in Bulk (Excel/CSV)

    
Columns needed: SKU and Quantity. Optional: Warehouse (must match an existing name exactly — omit this column entirely if this client tracks one overall stock pool rather than separate warehouses, and every row lands in the default warehouse instead), Low Stock Threshold, and Brand (checked against this client's registered brand name(s), if any are set in Client Administration — a mismatched file is rejected outright, not partially processed). Only adds brand-new SKUs — a SKU already being tracked here is left alone, never reset by a re-upload, since real sales are continuously adjusting it in the background.
